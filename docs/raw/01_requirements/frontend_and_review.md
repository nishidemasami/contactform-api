# フロントエンドおよびレビュー資料 要件定義

## テスト用フロントエンド (SPA) 要件
- **目的**: 簡易的なテスト用フロントエンドとして静的SPAサイトを作成する。テストの実行を主目的としつつ、Next.jsのリファレンス実装を兼ねる。
- **デプロイ制限**: `release` ステージ（本番環境）ではフロントエンドは一切デプロイしない。`develop` ステージのみデプロイ。
- **機能要件**:
  - 投稿部: 氏名テキストボックス、連絡先テキストボックス、本文テキストエリア、投稿ボタン、利用規約同意チェックボックス、利用規約ダイアログリンク。
  - 通信処理: 投稿ボタン押下時に `POST /api/v1/inquiry` を呼び出す。
  - 利用規約ダイアログ: 利用規約リンク押下時にセキュリティ免責事項・個人情報取扱・ログ取得に関する注意事項をモーダル表示。

## レビュー資料 (Review Assets) 要件
- **目的**: プルリクエスト作成・更新時に自動ビルド・デプロイされる静的Webコンテンツ。
- **デプロイ制限**: `release` ステージでは一切デプロイしない。
- **コンテンツ要件**:
  - エンジニアリング仕様書（HonKitドキュメント）
  - 自動テスト・カバレッジレポート（cargo-tarpaulin HTML）
  - バックエンドAPIドキュメント（Rust Doc）
  - インタラクティブAPIドキュメント（Stoplight Elements / RapiDoc）
  - フロントエンド検証環境（Storybook）
  - フロントエンドAPIドキュメント（TypeDoc）
