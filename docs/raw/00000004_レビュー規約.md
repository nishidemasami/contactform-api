# 00000004_レビュー規約

本ドキュメントは、本システム開発におけるプルリクエスト（PR）の作成、自動テスト、カバレッジ計測、およびレビュー用のプレビュー環境（レビュー資料）のビルドから自動デプロイまでの開発・レビュープロセスに関する規約を定めたものである。

---

## 1. 開発およびレビュープロセスの全体設計

本プロジェクトでは、すべての機能変更、リファクタリング、およびバグ修正はプルリクエスト（PR）を経由してレビューおよびマージされなければならない。

### 1.1. プルリクエストをトリガーとしたレビュー資料の自動生成
GitHubリポジトリに対するすべてのプルリクエストの作成または更新を契機として、CI/CDパイプライン（GitHub Actions）が自動的に起動する。
CI/CDパイプラインは、ソースコードの妥当性を検証するだけでなく、プルリクエスト専用の「レビュー資料」を一括ビルドし、AWS上に自動でデプロイ（ホスティング）する。

開発者およびレビューアーは、PR上のGitHub Deployment機能や自動コメント等によって通知されるURLから、以下の資料を動的に参照し、レビューの判断材料とする。

### 1.2. レビュー資料として提供されるコンテンツ一覧
自動デプロイされるレビュー資料ディレクトリは、以下の資産を包含する：

- **エンジニアリング仕様書（HonKitドキュメント）**: 本プロジェクトの設計規約、インフラ・DB構成、実装仕様がMarkdownからコンパイルされたHTMLサイト（`/index.html`）。
- **自動テスト・カバレッジレポート（tarpaulin）**: `cargo tarpaulin` が測定した、行カバレッジ・関数カバレッジの視覚的レポート（`/coverage/tarpaulin-report.html`）。
- **バックエンドAPIドキュメント（Rust Doc）**: `cargo doc` を用いて、実装コメントから自動生成されたRust APIリファレンス（`/rust-doc/`）。
- **インタラクティブAPIドキュメント（Stoplight Elements / RapiDoc）**: OpenAPI仕様（`openapi.yaml`）から自動ビルドされた、ブラウザ上で実際にリクエスト・レスポンスをテスト可能なAPIカタログ（`/stoplight/index.html` および `/rapidoc/index.html`）。
- **フロントエンド検証環境（Storybook）**: UIコンポーネントを単体で画面上で検証・確認するためのStorybookビルド済み資産（`/storybook/`）。
- **フロントエンドAPIドキュメント（TypeDoc）**: TypeScriptのコードアノテーションから自動生成された詳細ドキュメント（`/typedoc/`）。

---

## 2. レビュー資料管理用 CI/CD パイプライン仕様

以下に、レビュー資料を収集、テスト、ビルド、デプロイ、およびキャッシュコントロール（CloudFront invalidation）までを一気通貫で行うGitHub Actionsのワークフロー定義ファイルを示す。

本CI/CDは、ローカル環境用のインメモリDB（PostgreSQL）をGitHub Actionsのサービスコンテナ機能を用いて動的に立ち上げ、テストを実行するため、ディスクにゴミを残さず、クリーンかつ安定した実行が可能である。

```yaml
name: example-service レビュー資料管理 CI/CD

on:
  workflow_dispatch:
    inputs:
      stage:
        description: デプロイステージ
        required: true
        default: develop
        type: choice
        options:
          - develop
          - release
  pull_request:
    paths:
      - "api/**"
      - "core/**"
      - "db/sea_orm_entities/**"
      - "docs/**"
      - "frontend/**"
      - "review/**"
      - ".github/workflows/review-cicd.yaml"

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

permissions:
  id-token: write
  contents: read
  deployments: write

jobs:
  validate:
    name: validate
    runs-on: ubuntu-latest
    # 💡 Postgresは「services」機能で立ち上げる
    # ジョブ終了時にGitHub側が自動で完全にクリーンアップするため、ディスクにゴミが残りません。
    services:
      postgres:
        image: postgres:16-alpine # 💡 Alpine版を使ってイメージ自体の容量を削減
        env:
          POSTGRES_DB: postgres
          POSTGRES_USER: postgres
          POSTGRES_PASSWORD: postgres
        ports:
          - 5432:5432
        # 起動を確実にするためのヘルスチェック
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - name: リポジトリのチェックアウト
        uses: actions/checkout@v7

      - name: Rustツールチェーンのセットアップ
        uses: dtolnay/rust-toolchain@stable

      - name: Node.jsのセットアップ
        uses: actions/setup-node@v6
        with:
          node-version: "24"
          cache: "npm"
          cache-dependency-path: frontend/package-lock.json

      - name: AWS SAM CLIのセットアップ
        uses: aws-actions/setup-sam@v3

      - name: デプロイステージの設定
        id: stage
        run: |
          # 手動入力(inputs.stage)があればそれを使い、なければbase_refで判定する
          if [ -n "${{ github.event.inputs.stage }}" ]; then
            echo "stage=${{ github.event.inputs.stage }}" >> "$GITHUB_OUTPUT"
            echo "commitid=${{ github.sha }}" >> "$GITHUB_OUTPUT"
          elif [ "${{ github.base_ref }}" = "release" ]; then
            echo "stage=release" >> "$GITHUB_OUTPUT"
            echo "commitid=${{ github.event.pull_request.head.sha }}" >> "$GITHUB_OUTPUT"
          else
            echo "stage=develop" >> "$GITHUB_OUTPUT"
            echo "commitid=${{ github.event.pull_request.head.sha }}" >> "$GITHUB_OUTPUT"
          fi
          echo "service_name=example-service" >> "$GITHUB_OUTPUT"

      - name: sam validate --lint の実行
        env:
          AWS_DEFAULT_REGION: ap-northeast-3
        run: sam validate --lint --template-file review/template.yaml

      - name: Liquibaseのセットアップ
        uses: liquibase/setup-liquibase@v3
        with:
          version: "4.33.0"
          edition: "community"

      - name: Liquibaseでローカルマイグレーション
        run: |
          liquibase \
            --search-path="${{ github.workspace }}" \
            update \
            --changelog-file=db/liquibase/changelog.xml \
            --context-filter=local \
            --url=jdbc:postgresql://localhost:5432/postgres \
            --username=postgres \
            --password=postgres \
            -DStage=local \
            -DAWS_ACCOUNT_ID=123456789012

      - name: Rust cache
        uses: swatinem/rust-cache@v2

      - name: cargo-tarpaulinのインストール
        run: cargo install cargo-tarpaulin --locked

      - name: カバレッジレポートの生成
        run: cargo tarpaulin --out Html -- --include-ignored

      - name: Rustドキュメントの生成
        run: cargo doc --no-deps

      - name: OpenAPI仕様の生成
        working-directory: api/lambda
        run: cargo run --bin export_openapi

      - name: npmパッケージのインストール
        working-directory: frontend
        run: npm ci

      - name: Storybookのビルド
        working-directory: frontend
        run: npm run build-storybook

      - name: TypeDocの生成
        working-directory: frontend
        run: npm run build:typedoc

      - name: コミット情報を付与し、docsディレクトリをHTMLに変換
        working-directory: docs
        run: |
          echo '## コミット情報' >> README.md
          echo '- コミットID：[${{ steps.stage.outputs.commitid }}](https://github.com/***/example-service-repository/tree/${{ steps.stage.outputs.commitid }})' >> README.md
          echo '- ステージ：${{ steps.stage.outputs.stage }}' >> README.md
          echo '- プルリクエスト：<${{ github.event.pull_request.html_url }}>' >> README.md
          docker run --rm -u $(id -u):$(id -g) -v .:/honkit ghcr.io/nishidemasami/markdown-docs:v1.2.3 npx honkit build

      - name: レビュー資料の収集
        run: |
          mkdir -p review-output/coverage review-output/rust-doc review-output/storybook review-output/typedoc
          cp -r docs/_book/. review-output/
          cp tarpaulin-report.html review-output/coverage/tarpaulin-report.html
          cp -r target/doc/. review-output/rust-doc/
          cp api/openapi.yaml review-output/
          cp -r frontend/storybook-static/. review-output/storybook/
          cp -r frontend/typedoc/. review-output/typedoc/

      - name: Generate Stoplight Elements
        run: |
          mkdir -p review-output/stoplight
          cat <<'EOF' > review-output/stoplight/index.html
          <!doctype html>
          <html>
            <head>
              <meta charset="utf-8" />
              <script src="https://unpkg.com/@stoplight/elements@9.0.23/web-components.min.js" integrity="sha384-Kx8v0VsAmmNDqBDAOnY3pQFLUNZNwhakX114rKqExXeXBbDgXHBvasXBU8QxWSMB" crossorigin="anonymous"></script>
              <link rel="stylesheet" href="https://unpkg.com/@stoplight/elements/styles.min.css">
            </head>
            <body>
              <elements-api
                apiDescriptionUrl="../openapi.yaml"
                router="hash"
              />
            </body>
          </html>
          EOF

      - name: Generate RapiDoc HTML
        run: |
          mkdir -p review-output/rapidoc
          cat <<'EOF' > review-output/rapidoc/index.html
            <!doctype html>
            <html>
              <head>
                <meta charset="utf-8" />
                <script src="https://unpkg.com/amazon-cognito-identity-js@6.3.20/dist/amazon-cognito-identity.min.js" integrity="sha512-SQetvX8cBgnpMAL46pScfHIn83W6ogqCCoMTHSgscbLIYJjJ5iamF0OAz84uLlE4eg8XJXYY+j1wyUqPnQ1N5w==" crossorigin="anonymous"></script>
                <script src="https://unpkg.com/rapidoc@9.3.8/dist/rapidoc-min.js" integrity="sha512-0ES6eX4K9J1PrIEjIizv79dTlN5HwI2GW9Ku6ymb8dijMHF5CIplkS8N0iFJ/wl3GybCSqBJu8HDhiFkZRAf0g==" crossorigin="anonymous"></script>
              </head>
              <body>
                <rapi-doc style="visibility: visible" id="doc" spec-url="../openapi.yaml" render-style="read" allow-try="true" allow-authentication="true" persist-auth="true" theme="dark" show-header="false" api-key-name="Authorization" api-key-location="header"></rapi-doc>
              </body>
            </html>
          EOF

      - name: アーティファクトのアップロード
        uses: actions/upload-artifact@v7
        with:
          name: review-docs
          path: review-output/

  deploy:
    name: デプロイ
    needs: validate
    runs-on: ubuntu-latest
    steps:
      - name: リポジトリのチェックアウト
        uses: actions/checkout@v7

      - name: AWSクレデンシャルの設定
        uses: aws-actions/configure-aws-credentials@v6
        with:
          role-to-assume: ${{ secrets.AWS_DEPLOY_ROLE_ARN }}
          aws-region: ap-northeast-3

      - name: AWS SAM CLIのセットアップ
        uses: aws-actions/setup-sam@v3

      - name: デプロイステージの設定
        id: stage
        run: |
          # 手動入力(inputs.stage)があればそれを使い、なければbase_refで判定する
          if [ -n "${{ github.event.inputs.stage }}" ]; then
            echo "stage=${{ github.event.inputs.stage }}" >> "$GITHUB_OUTPUT"
            echo "commitid=${{ github.sha }}" >> "$GITHUB_OUTPUT"
            echo "subdirectoryname=${{ github.sha }}" >> "$GITHUB_OUTPUT"
            echo "deployment_environment=${{ github.event.inputs.stage }}レビュー資料" >> "$GITHUB_OUTPUT"
          elif [ "${{ github.base_ref }}" = "release" ]; then
            echo "stage=release" >> "$GITHUB_OUTPUT"
            echo "commitid=${{ github.event.pull_request.head.sha }}" >> "$GITHUB_OUTPUT"
            echo "subdirectoryname=pull_request/${{ github.event.pull_request.number }}" >> "$GITHUB_OUTPUT"
            echo "deployment_environment=プルリクエスト#${{ github.event.pull_request.number }}レビュー資料" >> "$GITHUB_OUTPUT"
          else
            echo "stage=develop" >> "$GITHUB_OUTPUT"
            echo "commitid=${{ github.event.pull_request.head.sha }}" >> "$GITHUB_OUTPUT"
            echo "subdirectoryname=pull_request/${{ github.event.pull_request.number }}" >> "$GITHUB_OUTPUT"
            echo "deployment_environment=プルリクエスト#${{ github.event.pull_request.number }}レビュー資料" >> "$GITHUB_OUTPUT"
          fi
          echo "service_name=example-service" >> "$GITHUB_OUTPUT"

      - name: sam deploy の実行
        run: |
          sam deploy \
            --template-file review/template.yaml \
            --stack-name ${{ steps.stage.outputs.service_name }}-review-${{ steps.stage.outputs.stage }} \
            --role-arn ${{ secrets.SAM_DEPLOY_ROLE_ARN }} \
            --parameter-overrides \
              Stage=${{ steps.stage.outputs.stage }} \
              SecretReferer="${{ secrets.SECRET_REFERER }}" \
            --capabilities CAPABILITY_IAM \
            --no-confirm-changeset \
            --no-fail-on-empty-changeset \
            --resolve-s3

      - name: アーティファクトのダウンロード
        uses: actions/download-artifact@v8
        with:
          name: review-docs
          path: review-output/

      - name: コミットIDとスタック情報の取得
        id: cloudformation_info
        run: |
          BUCKET_NAME=$(aws cloudformation describe-stacks \
            --stack-name ${{ steps.stage.outputs.service_name }}-review-${{ steps.stage.outputs.stage }} \
            --query "Stacks[0].Outputs[?OutputKey=='ReviewBucketName'].OutputValue" \
            --output text)
          echo "bucket_name=$BUCKET_NAME" >> "$GITHUB_OUTPUT"

          CLOUDFRONT_DOMAIN=$(aws cloudformation describe-stacks \
            --stack-name ${{ steps.stage.outputs.service_name }}-review-${{ steps.stage.outputs.stage }} \
            --query "Stacks[0].Outputs[?OutputKey=='CloudFrontDomainName'].OutputValue" \
            --output text)
          echo "review_cloudfront_domain=$CLOUDFRONT_DOMAIN" >> "$GITHUB_OUTPUT"

          FRONTEND_CLOUDFRONT_DOMAIN=$(aws cloudformation describe-stacks \
            --stack-name ${{ steps.stage.outputs.service_name }}-frontend-${{ steps.stage.outputs.stage }} \
            --query "Stacks[0].Outputs[?OutputKey=='CloudFrontDomainName'].OutputValue" \
            --output text)
          echo "frontend_cloudfront_domain=$FRONTEND_CLOUDFRONT_DOMAIN" >> "$GITHUB_OUTPUT"

          DISTRIBUTION_ID=$(aws cloudformation describe-stacks \
            --stack-name ${{ steps.stage.outputs.service_name }}-review-${{ steps.stage.outputs.stage }} \
            --query "Stacks[0].Outputs[?OutputKey=='ReviewCloudFrontDistributionId'].OutputValue" \
            --output text)
          echo "distribution_id=$DISTRIBUTION_ID" >> "$GITHUB_OUTPUT"

      - name: openapi.yamlのAPIエンドポイント情報の追加
        run: |
          echo "" >> review-output/openapi.yaml
          echo "servers:" >> review-output/openapi.yaml
          echo "- url: https://${{ steps.cloudformation_info.outputs.frontend_cloudfront_domain }}" >> review-output/openapi.yaml

      - name: GitHub Deploymentの作成
        id: deployment
        uses: actions/github-script@v9
        with:
          script: |
            const result = await github.rest.repos.createDeployment({
              owner: context.repo.owner,
              repo: context.repo.repo,
              ref: '${{ steps.stage.outputs.commitid }}',
              environment: '${{ steps.stage.outputs.deployment_environment }}',
              auto_merge: false,
              required_contexts: [],
              description: 'レビュー資料の公開'
            });
            return result.data.id;
          result-encoding: string

      - name: S3へのアップロード
        run: |
          aws s3 sync review-output/ \
            s3://${{ steps.cloudformation_info.outputs.bucket_name }}/${{ steps.stage.outputs.subdirectoryname }}/ \
            --delete

      - name: CloudFrontのキャッシュ削除
        run: |
          aws cloudfront create-invalidation \
            --distribution-id ${{ steps.cloudformation_info.outputs.distribution_id }} \
            --paths "/${{ steps.stage.outputs.subdirectoryname }}/*"

      - name: GitHub Deployment Statusの更新
        if: success()
        uses: actions/github-script@v9
        with:
          script: |
            await github.rest.repos.createDeploymentStatus({
              owner: context.repo.owner,
              repo: context.repo.repo,
              deployment_id: ${{ steps.deployment.outputs.result }},
              state: 'success',
              environment_url: 'https://${{ steps.cloudformation_info.outputs.review_cloudfront_domain }}/${{ steps.stage.outputs.subdirectoryname }}/index.html',
              description: 'レビュー資料の公開完了'
            });

      - name: Mark deployment failure
        if: failure() && steps.deployment.outputs.result != ''
        uses: actions/github-script@v9
        with:
          script: |
            await github.rest.repos.createDeploymentStatus({
              owner: context.repo.owner,
              repo: context.repo.repo,
              deployment_id: ${{ steps.deployment.outputs.result }},
              state: 'failure'
            })
```
