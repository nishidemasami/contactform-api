# 00000005_GitHub設定

## リポジトリに関する概要

AIによるシステム開発を円滑に実施するため、モノレポ構成とする。
これは、CI/CD、IaC、ドキュメント、プログラム、バックログ等を全てテキストベースで格納することにより、AIによるスムーズなシステム開発を可能にし、かつ、人間の新規参画時の参入障壁を最小化することを目的とする。

## リポジトリ構成

- / ： リポジトリルート
  - /.github/workflows ： CI/CDのGitHub Actions定義格納ディレクトリ
  - /README.md ： 概要を記載する。
  - /AGENTS.md ： AI向けプロンプトを記述する。上記README.mdを参照することを明記。
  - /BACKLOG.md ： バックログや懸念事項等のほか、アイデアやビジョンなども随時追記しメンテナンスする。
  - /api ： API用サブシステム格納ディレクトリ
  - /auth ： 認証用サブシステム格納ディレクトリ
  - /core ： ビジネスロジック格納ディレクトリ
  - /db ： DB用サブシステム格納ディレクトリ
  - /docs ： 基本設計書格納ディレクトリ
  - /frontend ： フロントエンド用サブシステム格納ディレクトリ
  - /retained : 永続的インフラリソース管理用ディレクトリ
  - /review ： レビュー資料デプロイ用サブシステム格納ディレクトリ

## ブランチ保護

- `Require signed commits` ： ON
  署名付きのコミットのみマージできるようになる
- `Require a pull request before merging` ： ON
  該当のブランチにコミットをpushすることができなくなり、プルリクエストの承認が必須になる
- `Require status checks to pass before merging` ： ON  
  自動テストなどをパスすることが必須となる
  - `Require branches to be up to date before merging` ： ON  
    自動テストが、マージする対象の最新資産から修正したものであることが必須となる
  - `Status checks that are required` ： 各CI/CDのvalidateを指定する  
    パス必須にするチェック名（「<workflow name> / <job name>」の形式で一覧から選択する）
- `Automatically request Copilot code review` ： ON  
  プルリクエストをAI(GitHub Copilot)が自動でレビューする
- `Restrict deletions` ： ON
- `Block force pushes` ： ON

※リポジトリがPublicの場合、以下の設定をする

- `Require a pull request before merging`
  - `Require review from Code Owners` ： ON  
    コードオーナーのレビューが必須となる

## GitHub Actionsで使用するsecrets

以下は`Environment secrets`として設定する。

| 設定名 | 設定値 |
|--|--|
| AWS_DEPLOY_ROLE_ARN | GitHub Actionsで`aws-actions/configure-aws-credentials@v6`の`role-to-assume`に指定するARN |
| SAM_DEPLOY_ROLE_ARN | `sam deploy --role-arn`で指定するCloudFormation実行ARN |
| SECRET_REFERER | CloudFrontとS3間の`aws:referer`に使用するランダムな文字列 |

※リポジトリがPublicの場合、以下の設定をする

- `Deployment protection rules`
  - `Required reviewers` ： ON  
    コードオーナーのレビューが必須となる
