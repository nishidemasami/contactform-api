# 00000009_フロントエンド規約と実装例

## フロントエンド 概要

- 静的SPAサイトリファレンス実装
  - 実装フレームワーク：Next.js
  - 実装言語：TypeScript
  - 概要：URLのパスルーティングでページを構成するためのリファレンス実装。ビルド生成成果物のHTMLファイルは`index.html`に出力し、CDNからは常にこのファイルの内容をクライアントに返す。本番実装ではNext.jsでSSGによりデプロイされる想定。
  - デザイン：Tailwind CSSによりデザインを実装する。マテリアルデザインで、どんな端末でも見やすいレスポンシブデザインとする。ダークモードは不要。
  - ビルド：ビルドはCI/CDで実行する。
    - JavaScriptのサプライチェーン攻撃の脅威を軽減することを目的として、以下の施策を実施する。
      - ビルドするjobの持つ権限は最小限にし、値の受け渡しは`jobs.<job_id>.outputs`により、ビルド成果物の受け渡しは`actions/upload-artifact`および`actions/download-artifact`により、それぞれ実施する。
      - ビルドは`npm`により実施する。
      - CI/CDに`npm audit`を組み込む。
    - 環境変数：ビルド時に、環境変数から以下の値を参照してSPAサイトに静的に埋め込む。
      - ※今回は不要。
  - 通信処理部
    - URL ： APIのエンドポイント。絶対パスで`/api/*`。 ※CloudFrontでルーティングしているのでFQDNは同一。
    - headers:
      - 'Content-Type': 'application/json'
    - API
      - 問い合わせ投稿API ： POST `/api/v1/inquiry`
        - body: JSON.stringify(以下の通り)
          - "name": 氏名テキストボックスの文字列
          - "email": 連絡先テキストボックスの文字列
          - "message": 本文テキストエリアの文字列
  - 認証部 ※今回は認証は不要なので以下は参考。
      - 認証は`aws-amplify`を使用して実装する。
      - `aws-amplify`の設定は`Amplify.configure`で設定する。AuthのCognitoの`userPoolId`、および`userPoolClientId`はCI/CDのビルド時に環境変数の値をセットする。この環境変数はCI/CDでAWS SAMの`aws cloudformation describe-stacks`で取得したもの。
  - ページ構成
    - トップページ：適当な説明文を表示する。ログインページへのリンクはわかりやすい場所に配置する(※今回は認証は無いためログインページは不要。)。
    - マイページ：(※今回は認証は無いため不要。)パスワード変更や退会、ログアウトなどができる。退会は`aws-amplify/auth`の`deleteUser`をコールするだけで、チャットデータの削除などは実施しない。
    - 問い合わせページ
      - 投稿部：氏名テキストボックス・連絡先テキストボックス・本文テキストエリア・投稿ボタン・利用規約同意チェックボックスおよびそのラベルとしての利用規約リンク。文字数チェックはしない。投稿ボタンで問い合わせ投稿APIを実行する。
    - 利用規約ダイアログ：利用規約リンク押下時に以下の内容を小さくダイアログ表示する。ダイアログは画面を覆わない大きさ。右上に閉じる×ボタンを表示し背景が薄くグレーアウトする。閉じるボタン押下時および背景押下時にダイアログは消える。
      ```text
      送信された情報はセキュリティ規格に関する国際規格であるISO/27001に準拠しているサービス(AWS、CloudFlare、GitLab、Slack、GitHub Actions、Google Cloud Platform)のみを利用して取り扱い、万全のセキュリティ体制により適切に取り扱いますが、このサービスを利用したことに起因して何かしらの損害が発生しても、直接損害か間接損害か否か、予見できたか否かを問わず、一切の責任を負いません。
      送信された内容は、このウェブサイトの運営のため、日本語ドキュメントによる技術的知見の普及のため、および送信者との連絡のためにのみ使用します。
      送信された内容は、職務上守秘義務を負う情報とはみなされません。
      送信された内容によって、いかなる契約も成立することはありません。
      IPアドレスなどの送信元情報をログとして保存しており、違法性がある場合または法令に基づく場合に限り、セキュリティ団体や捜査機関などに情報を提供する場合があります。
      AIおよび人力によるスパムフィルタによりフィルタリングを実施しており、もしスパムでなくても送信された内容がスパムと誤判定されて届かないことがあります。また、届いたお問い合わせに対して必ず返信することを約束するものではありません。
      以上についてご了承下さい。
      ```
  - 共通部
    - ヘッダー：ページ上部に固定するアプリケーションバー。バーの左端にハンバーガーメニュー。真ん中にはページタイトル（※文字列を表示するのに幅が足りない場合は`text-overflow: ellipsis`で省略する）。
    - フッター：著作権表示。万国著作権条約に従う。
    - メニュー：ハンバーガーメニューを押したときに表示する。各ページへのリンクをリストアップする。
    - トースター：成功時や失敗時のメッセージを表示する。×ボタン押下で消える。自動的は消えない。
  - 特記事項
    - 各コンポーネントはStorybookでのテスト・確認の実施が容易なように、Presentational and Container Componentsパターンを意識して実装すること。

## CI/CD

- jobs
  - validate
    - `sam validate --lint`で`/frontend/template.yaml`を検証する。
    - `npx tsc --noEmit`でコンパイルチェック
    - `pnpm run lint`で静的解析
    - `pnpm test`でユニットテストを実行する。
    - `pnpm audit`で脆弱性診断を実行する。
  - configure
    - SSM Parameterから値を取得するjob。今回はuserPoolClientIdなどが無いため不要。
  - build
    - `pnpm next build`でビルドを実行する。
    - `pnpm next export`で出力する。
  - deploy
    - AWSのクレデンシャルの設定
    - authのExportされた値を取得
    - `sam build`でビルド
    - `sam deploy`でデプロイ
    - `npm run build`で静的ファイルを生成し、CloudFormation の Output から取得した S3 バケットへ `aws s3 sync out/ ... --delete` で反映する。

## フロントエンド インフラ構成

### 推奨構成
- 本番環境では、CloudFront + S3 REST API origin + OAC を推奨する。
- S3 Website Endpoint + Referer制御は、OACが使えないため推奨構成ではない。採用する場合は、簡易的な直接アクセス抑止に留まることを明記する。
- SPAのパスルーティングは、CloudFront Custom Error ResponseまたはCloudFront FunctionによるURI rewriteで対応する。

### `/frontend/template.yaml`の実装例

> 注意: 以下はS3 Website EndpointをCustom Originとして使う簡易構成例である。以下はreleaseではデプロイしない。

```yaml
Parameters:
  ServiceName:
    Type: String
    Description: サービス名
  Stage:
    Type: String
    AllowedValues:
      - develop
    Description: デプロイステージ
  SecretReferer:
    Type: String
    NoEcho: true
    Description: シークレットトークン
  SubSystem:
    Type: String
    Default: frontend
    AllowedValues:
      - frontend
    Description: サブシステム分類名
  # --parameter-overrides ApiGatewayDomain="/${{ steps.info.outputs.stage }}/${{ steps.info.outputs.service_name }}/api/ApiGatewayDomain"
  ApiGatewayDomain:
    Type: AWS::SSM::Parameter::Value<String>
    Default: /develop/example-service/api/ApiGatewayDomain
    Description: "SSM Parameter Path for ApiGatewayDomain"
  # --parameter-overrides FrontendWebsiteURL="/${{ steps.info.outputs.stage }}/${{ steps.info.outputs.service_name }}/retained/FrontendWebsiteURL"
  FrontendWebsiteURL:
    Type: AWS::SSM::Parameter::Value<String>
    Default: /develop/example-service/retained/FrontendWebsiteURL
    Description: "SSM Parameter Path for FrontendWebsiteURL"
  # --parameter-overrides ReviewWebsiteURL="/${{ steps.info.outputs.stage }}/${{ steps.info.outputs.service_name }}/retained/ReviewWebsiteURL"
  ReviewWebsiteURL:
    Type: AWS::SSM::Parameter::Value<String>
    Default: /develop/example-service/retained/ReviewWebsiteURL
    Description: "SSM Parameter Path for ReviewWebsiteURL"

Conditions:
  IsRelease: !Equals [!Ref Stage, release]

Resources:
  # CloudFrontディストリビューション
  CloudFrontDistribution:
    Type: AWS::CloudFront::Distribution
    # releaseステージはデータ保護のため削除を禁止し、developステージは環境の再作成を容易にするため削除を許可する
    DeletionPolicy: !If [IsRelease, Retain, Delete]
    UpdateReplacePolicy: !If [IsRelease, Retain, Delete]
    Properties:
      DistributionConfig:
        Enabled: true
        HttpVersion: http2and3
        # トップページ（例: index.html）の自動補完設定 ※これはサブディレクトリには適用されないため注意
        DefaultRootObject: index.html
        Origins:
          - Id: ReviewS3WebsiteOrigin
            # レビュー資料格納用S3のドメイン
            DomainName: !Ref ReviewWebsiteURL
            CustomOriginConfig:
              HTTPPort: 80
              HTTPSPort: 443
              OriginProtocolPolicy: http-only # S3ウェブサイトホスティングはHTTPのみ対応
            OriginCustomHeaders:
              - HeaderName: "Referer"
                HeaderValue: !Ref SecretReferer
          - Id: FrontendS3WebsiteOrigin
            # フロントエンドSPA格納用S3のドメイン
            DomainName: !Ref FrontendWebsiteURL
            CustomOriginConfig:
              HTTPPort: 80
              HTTPSPort: 443
              OriginProtocolPolicy: http-only # S3ウェブサイトホスティングはHTTPのみ対応
            OriginCustomHeaders:
              - HeaderName: "Referer"
                HeaderValue: !Ref SecretReferer
          # API Gatewayオリジン
          - Id: ApiGatewayOrigin
            DomainName: !Ref ApiGatewayDomain
            CustomOriginConfig:
              HTTPSPort: 443
              OriginProtocolPolicy: https-only
        DefaultCacheBehavior:
          TargetOriginId: FrontendS3WebsiteOrigin
          ViewerProtocolPolicy: redirect-to-https # HTTPアクセスを自動でHTTPSにリダイレクト
          AllowedMethods:
            - GET
            - HEAD
          CachedMethods:
            - GET
            - HEAD
          # 拡張されたキャッシュポリシー（推奨：CachingOptimized）
          CachePolicyId: 658327ea-f89d-4fab-a63d-7e88639e58f6 # CachingOptimized
          Compress: true
        CacheBehaviors:
          # /review/* はレビュー資料格納用S3へルーティングする
          - PathPattern: /review/*
            TargetOriginId: ReviewS3WebsiteOrigin
            ViewerProtocolPolicy: redirect-to-https # HTTPアクセスを自動でHTTPSにリダイレクト
            AllowedMethods:
              - GET
              - HEAD
            CachedMethods:
              - GET
              - HEAD
            # 拡張されたキャッシュポリシー（推奨：CachingOptimized）
            CachePolicyId: 658327ea-f89d-4fab-a63d-7e88639e58f6 # CachingOptimized
            Compress: true
          # /api/* はAPI Gatewayへルーティングする
          - PathPattern: /api/*
            TargetOriginId: ApiGatewayOrigin
            ViewerProtocolPolicy: redirect-to-https
            CachePolicyId: 4135ea2d-6df8-44a3-9df3-4b5a84be39ad # CachingDisabled
            OriginRequestPolicyId: b689b0a8-53d0-40ab-baf2-68738e2966ac # AllViewerExceptHostHeader
            AllowedMethods:
              - GET
              - HEAD
              - OPTIONS
              - PUT
              - PATCH
              - POST
              - DELETE
        # 日本を含むPriceClass_200を指定 ※CloudFormationおよびSAMは定額プランについて現在未対応のため、マネジメントコンソール上から手動で設定を実施する。
        PriceClass: PriceClass_200
```

## retained インフラ構成の実装例

### `/retained/template.yaml`

> 注意: 以下はWebsiteConfigurationを利用する簡易構成例である。本番ではPublic Access Blockを有効化し、CloudFront OACからのみS3 REST API originへアクセスさせる構成を優先する。

```yaml
Parameters:
  ServiceName:
    Type: String
    Description: サービス名
  Stage:
    Type: String
    AllowedValues:
      - develop
      - release
    Description: デプロイステージ
  SecretReferer:
    Type: String
    NoEcho: true
    Description: シークレットトークン
  SubSystem:
    Type: String
    Default: retained
    AllowedValues:
      - retained
    Description: サブシステム分類名

Conditions:
  IsRelease: !Equals [!Ref Stage, release]

Resources:
  # フロントエンドSPA格納用S3バケット
  FrontendBucket:
    Type: AWS::S3::Bucket
    # releaseステージはデータ保護のため削除を禁止し、developステージは環境の再作成を容易にするため削除を許可する
    DeletionPolicy: !If [IsRelease, Retain, Delete]
    UpdateReplacePolicy: !If [IsRelease, Retain, Delete]
    Properties:
      # パブリックアクセスブロックを部分的に解除（バケットポリシーで公開するため）
      PublicAccessBlockConfiguration:
        BlockPublicPolicy: false
        RestrictPublicBuckets: false
        BlockPublicAcls: true
        IgnorePublicAcls: true
      WebsiteConfiguration:
        IndexDocument: index.html
        ErrorDocument: index.html # SPAとしてエラーハンドリングもブラウザサイドで処理する

  # CloudFrontからS3へのアクセスを許可するバケットポリシー
  FrontendBucketPolicy:
    Type: AWS::S3::BucketPolicy
    Properties:
      Bucket: !Ref FrontendBucket
      PolicyDocument:
        Version: "2012-10-17"
        Statement:
          - Effect: Allow
            Principal: "*"
            Action: s3:GetObject
            Resource: !Sub ${FrontendBucket.Arn}/*
            Condition:
              StringEquals:
                "aws:Referer": !Ref SecretReferer

  # レビュー資料配信用S3バケット
  ReviewBucket:
    Type: AWS::S3::Bucket
    # releaseステージはデータ保護のため削除を禁止し、developステージは環境の再作成を容易にするため削除を許可する
    DeletionPolicy: !If [IsRelease, Retain, Delete]
    UpdateReplacePolicy: !If [IsRelease, Retain, Delete]
    Properties:
      # パブリックアクセスブロックを部分的に解除（バケットポリシーで公開するため）
      PublicAccessBlockConfiguration:
        BlockPublicPolicy: false
        RestrictPublicBuckets: false
        BlockPublicAcls: true
        IgnorePublicAcls: true
      WebsiteConfiguration:
        IndexDocument: index.html
        ErrorDocument: error.html

  # CloudFrontからS3へのアクセスを許可するバケットポリシー
  ReviewBucketPolicy:
    Type: AWS::S3::BucketPolicy
    Properties:
      Bucket: !Ref ReviewBucket
      PolicyDocument:
        Version: "2012-10-17"
        Statement:
          - Effect: Allow
            Principal: "*"
            Action: s3:GetObject
            Resource: !Sub ${ReviewBucket.Arn}/*
            Condition:
              StringEquals:
                "aws:Referer": !Ref SecretReferer

  FrontendBucketNameParameter:
    Type: AWS::SSM::Parameter
    Properties:
      Name: !Sub "/${Stage}/${ServiceName}/${SubSystem}/FrontendBucketName"
      Type: String
      Value: !Ref FrontendBucket
      Description: "FrontendBucket Name"
  FrontendWebsiteURLParameter:
    Type: AWS::SSM::Parameter
    Properties:
      Name: !Sub "/${Stage}/${ServiceName}/${SubSystem}/FrontendWebsiteURL"
      Type: String
      Value: !Select [2, !Split ["/", !GetAtt FrontendBucket.WebsiteURL]] # WebsiteURL（http://...）からドメイン部分だけを抽出
      Description: "FrontendBucket WebsiteURL"

  ReviewBucketNameParameter:
    Type: AWS::SSM::Parameter
    Properties:
      Name: !Sub "/${Stage}/${ServiceName}/${SubSystem}/ReviewBucketName"
      Type: String
      Value: !Ref ReviewBucket
      Description: "ReviewBucket Name"
  ReviewWebsiteURLParameter:
    Type: AWS::SSM::Parameter
    Properties:
      Name: !Sub "/${Stage}/${ServiceName}/${SubSystem}/ReviewWebsiteURL"
      Type: String
      Value: !Select [2, !Split ["/", !GetAtt ReviewBucket.WebsiteURL]] # WebsiteURL（http://...）からドメイン部分だけを抽出
      Description: "ReviewBucket WebsiteURL"
```
